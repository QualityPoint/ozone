# Ozone Frontend

Vue 3 + TypeScript SPA for the Ozone website, built on frappe-ui.

Documentation lives in [`../docs/frontend/`](../docs/frontend/README.md). Start with its README.

```bash
yarn dev          # dev server on :8080 (proxies Frappe on :8000)
yarn build        # production build into ../ozone/public/frontend
yarn type-check   # vue-tsc on project files
yarn test:run     # vitest
yarn lint         # biome
```
